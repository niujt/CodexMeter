# Codex Health 页面功能计划（免费版）

## 目标

把左侧导航从“视觉占位”变成可用的本地 Codex 用量分析工具。所有统计只读取用户授权的本机 Codex 记录；不上传会话内容、项目路径或 Token 数据。

> 截图中“健康报告”之外实际有五个菜单，而不是四个：使用趋势、模型与效率、项目与用量、预测与风险、历史记录。本计划全部覆盖。

## 1. 健康报告（已实现，持续收敛）

**用途**：一眼判断当前 7 天额度是否健康。

- 当前剩余额度、重置倒计时、状态颜色（绿色 / 黄色 / 红色）。
- 今天、近 7 天、本月 Token 概览。
- 当前会话上下文占用、近 7 天趋势、预测和活跃项目摘要。
- 菜单栏与桌面小组件只展示这一页的核心指标。

**完成标准**：数据与菜单栏、小组件一致；点击刷新后主页面、菜单栏和小组件同步更新。

## 2. 使用趋势

**用途**：回答“Token 在什么时候、因为什么使用得最多”。

### 页面内容

- 时间粒度切换：近 24 小时（按小时）、近 7 天（按天）、近 30 天（按天）。
- 折线 / 柱状图：总 Token、输入、输出、缓存输入可切换。
- 筛选器：全部、单一模型、单一项目路径。
- 摘要：峰值时间、日均 Token、较上一周期的增减百分比。

### 数据与规则

- 来源：已解析的本地会话记录时间戳及 Token 字段。
- 默认按本地时区聚合；没有 Token 的记录不计入图表。
- 项目筛选使用归一化后的工作目录路径，不读取项目文件内容。

**完成标准**：切换粒度和筛选条件后图表、汇总数字与列表同步变化；空数据有明确空状态。

## 3. 模型与效率

**用途**：回答“主要使用什么模型，以及每次任务的成本和耗时”。

### 页面内容

- 模型排行榜：Token 占比、请求 / 回合数、输入 / 输出比例。
- 效率指标：平均回合时长、P50 / P90 时长、单回合平均 Token。
- 时间范围：今天、近 7 天、近 30 天。
- 模型详情：趋势迷你图及该模型涉及的项目路径排行。

### 数据与规则

- 模型名从本地记录的模型字段归一化；未知模型归为“未标注模型”。
- 回合耗时由相邻事件时间戳估算；缺失时间戳的记录不参与耗时平均值。

**完成标准**：不把“Token 占比”误称为模型能力；每个效率数字都能追溯到统计口径。

## 4. 项目与用量

**用途**：按真实项目路径查看 Codex 消耗，而不是做待办或个人项目管理。

### 页面内容

- 自动识别项目路径排行榜：路径别名、Token、会话数、最近活动时间。
- 时间范围：今天、近 7 天、近 30 天、全部。
- 项目详情：该路径的模型分布、日趋势、最近会话列表。
- 手动添加项目目录：通过 macOS 文件夹选择器添加“关注项目”。
- 路径隐私：可设置显示完整路径、仅显示最后一级目录，或自定义别名。

### 数据与规则

- 自动来源：会话记录中的工作目录 / cwd / project 字段。
- 手动添加只保存安全书签和别名；不会扫描或上传项目源代码。
- 无路径的会话归入“未归属路径”，可在页面中隐藏。

**完成标准**：用户能明确知道每个统计项目对应哪个本地目录，并能删除关注目录或路径别名；页面不出现待办、日程等无关功能。

## 5. 预测与风险

**用途**：在额度即将耗尽前给出可解释的提醒。

### 页面内容

- 7 天额度预测：按 1 小时、6 小时、24 小时、周期平均四种速度加权。
- 结果：预计可用时长、预计耗尽时间、是否能撑到重置。
- 风险解释：当前消耗速度、历史平均速度、最主要消耗项目 / 模型。
- 提醒配置：阈值（5 / 10 / 20 / 30 / 50%）、同日去重、提前耗尽提醒、重置提醒。
- 最近提醒记录：何时、因何规则触发、是否已去重。

### 数据与规则

- 只在官方 7 天额度存在时展示预测；没有额度数据时显示原因，不编造结论。
- “可能耗尽”必须展示计算依据和不确定性，不使用绝对承诺。

**完成标准**：每次提醒可追溯；测试阈值可立即触发本地通知，且不会在同日反复打扰。

## 6. 历史记录

**用途**：回看长期用量和额度变化，支持用户自查。

### 页面内容

- 日 / 周 / 月汇总表：Token、会话数、活跃项目数、平均上下文占用。
- 7 天额度历史：剩余比例、重置时间、触发过的风险状态。
- 会话列表：时间、项目路径、模型、输入 / 输出 / 总 Token；可按日期、项目、模型筛选。
- 导出：CSV（汇总与匿名化会话统计）；不导出会话正文。
- 数据管理：清除本应用生成的历史汇总缓存，不删除 Codex 原始记录。

**完成标准**：历史列表支持大数据量分页 / 限量加载；导出前清楚说明字段和隐私范围。

## 实施顺序

1. **项目与用量**：先建立可靠的项目路径归一化和手动关注目录机制，作为后续筛选基础。
2. **使用趋势**：复用项目 / 模型筛选器，完成按小时、日、周期聚合。
3. **模型与效率**：基于同一批标准化记录增加模型和时长指标。
4. **预测与风险**：在已有历史速度数据基础上完善预测、通知和提醒日志。
5. **历史记录**：最后加入可查询的本地归档、导出和缓存管理。

## 非目标（免费版暂不做）

- 云同步、团队成员对比、远程项目扫描。
- 会话正文搜索、提示词内容分析、自动任务 / 待办管理。
- 付费订阅、账号系统或上传用户数据。
